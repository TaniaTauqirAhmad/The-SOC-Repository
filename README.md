# The-SOC-Repository
A Security Operations Center (SOC) repository, for students and professionals building, operating, and improving a modern SOC environment. Aiming for a systems-thinking perspective through modular design, by viewing SOCs as environments consisting of independent building blocks & by viewing SOCs as building blocks within business environments.
